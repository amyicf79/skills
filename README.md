# IXNO Skills — 进化引擎自动产出的 AI Agent 技能包

由 IXNO 进化引擎自动产出、验证、分发的 SKILL.md 技能包（开源版）。

## 安装
\`\`\`bash
bash install.sh            # 一键装到 Claude/Cursor/Codex/OpenCode/Gemini 等
# 或手动复制某个技能包到对应目录:
#   Claude Code: ~/.claude/skills/<skill-name>/
#   Cursor:      ~/.cursor/skills/<skill-name>/
\`\`\`

## 技能来源
- 引擎: IXNO evolver (进化算法, fitness 评分 + 验证关卡)
- 每包含: SKILL.md + scripts/execute.py + metadata(original_id/fitness)
- 原创产物, 自动版本迭代

## 平台支持
Claude Code / Cursor / Codex / OpenCode / Gemini CLI / GitHub Copilot / Kiro / Windsurf / 腾讯元宝(经SkillHub)
